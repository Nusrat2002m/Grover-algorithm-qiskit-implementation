# Grover's Search Algorithm using IBM Qiskit

This repository contains a Python implementation of **Grover's Unstructured Search Algorithm** built using **IBM Qiskit**.

## 📌 Project Overview
Grover's algorithm provides a quadratic speedup for unstructured search problems on quantum computers compared to classical algorithms ($O(\sqrt{N})$ vs $O(N)$). 

In this implementation:
- **Number of Qubits:** 3
- **Target State:** `101`
- **Framework:** Qiskit Aer Simulator

## 🚀 How to Run
1. Install dependencies:
   ```bash
   pip install qiskit qiskit-aer matplotlib

Run the script:

    python grovers_search.py
